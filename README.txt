# 18 Summers — GitHub Pages

## Files
- `index.html` — the website
- `style.css` — all styling
- `script.js` — the September 22, 2026 at 5:05 PM lock + animations
- `images/` — put your 18 photos here

## Add your photos
Rename your photos exactly:

`year-1.jpg`
`year-2.jpg`
...
`year-18.jpg`

Then put them inside the `images` folder.

PNG files also work if you change `.jpg` in `index.html` to `.png`.

## Important: the 5:05 lock
The site unlocks at **September 22, 2026 at 5:05 PM** according to the visitor's device clock.

Because this is a client-side GitHub Pages site, the lock is a fun reveal rather than high-security protection. Someone who changes their device clock or inspects the code could bypass it.

## Music
The site has a music button, but it intentionally does not contain the copyrighted song itself.

If you have a permitted/local copy, you can add it in the `<audio>` section of `index.html`. Otherwise, we can replace the button with a link/embed to a legitimate music service.

## GitHub Pages
1. Create/open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save.
7. GitHub will give you your Pages address.
